# Module 39: Authentication Advanced — Profile, Password and Email

A learning-focused authentication project built while studying **Module 39: Authentication Advanced — Profile, Password and Email**.

**Author:** Farhad Alom  
**Purpose:** This project was created only for learning and practice.

## 📚 Topics Covered

###  Module Intro & Setup Previous Project
- Continued the previous Better Auth project.
- Set up the authentication client and server configuration.
- Connected Better Auth with MongoDB.

###  Implement Google Authentication
- Added Google social authentication.
- Configured Google OAuth credentials.
- Implemented Google sign-in from the application.

###  Add Other Social Login Method
- Added GitHub authentication alongside Google.
- Implemented social sign-in using Better Auth.

###  Protect URL Only for the Logged-in User
- Protected `/dashboard` and `/profile`.
- Checked the current session on the server.
- Redirected unauthenticated users to `/sign-in`.
- Displayed authenticated-user navigation links conditionally.

###  Update Profile — Build Profile Update Form
- Created a profile settings form.
- Used Better Auth's `updateUser()` method to update the user's name.
- Added form validation and success feedback.

###  Email Verification — Send Verification Email
- Enabled email/password authentication with required email verification.
- Integrated **Resend** for sending verification emails.
- Configured verification email expiration and automatic sign-in after verification.

###  Send Verification Email and Verify Email
- Sent a verification link after registration.
- Used the verification URL generated by Better Auth.
- Tested the complete email verification flow with Resend.

###  Forgot Password Flow — Request Reset Link
- Built a Forgot Password form.
- Used Better Auth's `requestPasswordReset()`.
- Sent the password reset link through Resend.
- Configured the reset flow to redirect to the reset-password page.

###  Handle Reset Password Link and Allow Update Password
- Read the password reset token from the URL.
- Built a reset-password form with password validation.
- Used Better Auth's `resetPassword()` to update the password.
- Practiced handling the reset token and password update flow.

## 🛠️ Main Technologies

- Next.js
- React
- Better Auth
- MongoDB
- Resend
- HeroUI
- Google OAuth
- GitHub OAuth
- Tailwind CSS

## 🔐 Authentication Features

The project demonstrates a complete learning-oriented authentication flow:

**Sign Up → Email Verification → Sign In → Protected Dashboard/Profile → Profile Update**

and:

**Forgot Password → Reset Email → Reset Password**

Social authentication is also included through **Google** and **GitHub**.
